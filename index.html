Practice

Do this across all lessons, a few minutes at a time. It gets more useful the more lessons you have done.

Reading Challenge Flip cards covering Lessons 1–5: words, kanji and sentences, mixed. Read aloud, flip, grade yourself. Your misses are saved for the next session.

Reference

What you need

Two books, plus the publisher's free audio app. Everything on this site references the page numbers printed in the books, so it works with any copy you own.

OTO Navi — audio The publisher's free audio app. Search the textbook's ISBN inside it. Install before day 1 — the reading protocol needs it.

If you are starting today: read The Genki I Path first — particularly the box about what nine weeks actually buys. Install OTO Navi. Print the kana charts. Then open week 1, day 1.

This plan is a hypothesis, not a contract. It assumes an average pace through material that suits different people differently. Ask for it to be re-cut the moment it stops matching reality — if a lesson takes nine sessions instead of seven, that is information, not failure.
